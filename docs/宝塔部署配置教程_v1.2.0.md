## 三、部署步骤

### Step 1：上传源码到服务器

1. 将源码包 `strategy-trade-v1.2.0.zip` 上传到服务器 `/www/wwwroot/` 目录
2. 解压并重命名文件夹：

```bash
cd /www/wwwroot/
unzip strategy-trade-v1.2.0.zip
mv strategy-trade-v1.2.0 strategy-trade
cd strategy-trade
chmod +x deploy/install.sh deploy/upgrade.sh
```

### Step 2：创建 MySQL 数据库

宝塔面板 → 数据库 → 添加数据库：
- **库名**：`trading_system`
- **用户名**：`trading_user`
- **密码**：自己设置一个强密码（请记录下来，后面配置要用）
- **访问权限**：本地服务器 127.0.0.1
- **字符集**：`utf8mb4`

> 注意：不需要手动导入SQL，系统启动时会自动建表 + 初始化种子数据。

### Step 3：配置环境变量

```bash
cd /www/wwwroot/strategy-trade
cp .env.example .env
chmod 600 .env
vi .env
```

**必须修改的核心配置项：**

```env
# ====== 应用秘钥（必须修改！32位以上随机字符串）======
APP_SECRET_KEY=你的随机字符串至少32位

# ====== 数据库（MySQL）======
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=trading_user
DB_PASSWORD=你刚才设置的数据库密码
DB_NAME=trading_system
DB_CHARSET=utf8mb4
DB_SQLITE_FALLBACK=

# ====== Redis ======
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=你的Redis密码（没有就留空）
REDIS_DB=0

# ====== 交易所（至少配置一个，也可以先不配置，用公开行情模式）======
BINANCE_MAIN_API_KEY=
BINANCE_MAIN_API_SECRET=
BINANCE_TESTNET=true     # 建议先跑测试网
BINANCE_BASE_URL=https://testnet.binancefuture.com

OKX_MAIN_API_KEY=
OKX_MAIN_API_SECRET=
OKX_MAIN_PASSPHRASE=
OKX_TESTNET=false
OKX_BASE_URL=https://www.okx.com

# ====== 代理（国内服务器建议配置，用于新闻抓取）======
PROXY_ENABLED=false
PROXY_HTTP_LIST=

# ====== 跨域（生产环境建议配置为你的域名）======
CORS_ALLOW_ORIGINS=*
```

### Step 4：执行一键部署脚本

```bash
cd /www/wwwroot/strategy-trade
bash deploy/install.sh
```

**install.sh 会自动完成以下工作：**
1. 创建 Python 虚拟环境 `.venv`
2. 安装 Python 依赖（requirements.txt）
3. 安装前端依赖并构建（npm install + npm run build）
4. 初始化数据库表结构
5. 创建默认管理员账号（admin / Admin@2024）
6. 生成 Supervisor 配置文件

### Step 5：配置 Supervisor 进程守护

宝塔面板 → 软件商店 → Supervisor → 设置 → 添加守护进程

**需要添加 1-3 个进程（根据需求）：**

#### 进程 1：后端 API（必须）
- **名称**：`strategy-trade-api`
- **启动用户**：`root`
- **运行目录**：`/www/wwwroot/strategy-trade`
- **启动命令**：
  ```
  /www/wwwroot/strategy-trade/.venv/bin/python main.py
  ```
- **进程数量**：1

#### 进程 2：Celery Worker（可选，推荐生产环境开启）
- **名称**：`strategy-trade-worker`
- **启动用户**：`root`
- **运行目录**：`/www/wwwroot/strategy-trade`
- **启动命令**：
  ```
  /www/wwwroot/strategy-trade/.venv/bin/celery -A backend.core.celery_app worker -l info -Q scoring,risk,news,report,default
  ```
- **进程数量**：1

#### 进程 3：Celery Beat（可选，推荐生产环境开启）
- **名称**：`strategy-trade-beat`
- **启动用户**：`root`
- **运行目录**：`/www/wwwroot/strategy-trade`
- **启动命令**：
  ```
  /www/wwwroot/strategy-trade/.venv/bin/celery -A backend.core.celery_app beat -l info --max-interval 300
  ```
- **进程数量**：1

> 注意：不使用 Celery 时，系统默认使用 APScheduler（内置）执行定时任务，已足够满足大部分需求。

### Step 6：配置 Nginx 站点

#### 6.1 添加站点
宝塔面板 → 网站 → 添加站点：
- **域名**：你的域名（如 trade.example.com）
- **根目录**：`/www/wwwroot/strategy-trade/frontend/dist`
- **PHP版本**：纯静态

#### 6.2 配置 Nginx 反向代理
点击站点 → 设置 → 配置文件，将以下内容替换进去（修改 server_name 为你的域名）：

```nginx
server {
    listen 80;
    server_name 你的域名;
    
    # HTTP 强制跳转 HTTPS（配置SSL后取消注释）
    # return 301 https://$server_name$request_uri;
    
    # 敏感文件保护
    location ~ /\.(env|git|svn|ht|installed|gitignore) {
        deny all;
        return 404;
    }
    
    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
        proxy_connect_timeout 300s;
    }
    
    # Swagger 文档透传
    location /docs {
        proxy_pass http://127.0.0.1:8000/docs;
        proxy_set_header Host $host;
    }
    
    location /openapi.json {
        proxy_pass http://127.0.0.1:8000/openapi.json;
        proxy_set_header Host $host;
    }
    
    # 健康检查
    location /health {
        proxy_pass http://127.0.0.1:8000/health;
    }
    
    # 前端静态文件
    location / {
        root /www/wwwroot/strategy-trade/frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
        
        # 静态资源缓存
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
            expires 7d;
            add_header Cache-Control "public, immutable";
        }
    }
    
    # Gzip 压缩
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_types text/plain text/css text/xml text/javascript application/javascript application/json application/xml+rss application/xml;
}
```

#### 6.3 配置 HTTPS（推荐）
宝塔面板 → 站点设置 → SSL：
- 选择 Let's Encrypt 或上传你的SSL证书
- 开启「强制HTTPS」

### Step 7：验证部署是否成功

1. **健康检查**：浏览器访问 `http://你的域名/health`
   - 返回 `{"status":"ok"}` 表示后端运行正常

2. **登录系统**：浏览器访问 `http://你的域名`
   - 默认账号：`admin` / `Admin@2024`
   - 登录后请立即修改密码！

3. **功能验证**：
   - [ ] K线行情页面能正常打开
   - [ ] 布局菜单能切换不同布局模板
   - [ ] 自定义拖拽布局功能正常
   - [ ] 交易所子账号可以添加
   - [ ] 策略管理可以创建策略

## 六、常见问题

### Q1：K线页面不显示数据？
**A**：检查以下几点：
1. 是否选择了交易所子账号？可以选择「公开行情」模式无需绑定账号
2. 子账号 API Key 是否配置正确？连通性测试是否通过？
3. 浏览器 F12 控制台是否有报错？

### Q2：自定义布局保存后刷新不生效？
**A**：布局是按用户独立存储的，请确认：
1. 是否登录了正确的用户账号
2. 点击「完成编辑」后是否提示「布局已保存」
3. 浏览器 localStorage 是否被禁用

### Q3：超级管理员看不到K线？
**A**：超级管理员默认使用公开行情模式，如果绑定了演示子账号可能导致数据异常。
- 解决方案：子账号选择器选择「🌐 公开行情」即可正常显示

### Q4：不同用户布局串了？
**A**：v1.2.0 已修复此问题，布局按用户ID独立存储。
- 存储 key 格式：`kline_layout_u{用户ID}` 和 `kline_custom_layout_u{用户ID}`

### Q5：新闻抓取不到？
**A**：国内服务器需要配置代理：
1. 在 `.env` 中设置 `PROXY_ENABLED=true`
2. 配置 `PROXY_HTTP_LIST` 代理地址
3. 或者使用 NewsData.io / Alpha Vantage 等 API 源

## 七、安全建议

1. **修改默认密码**：登录后第一时间修改 admin 密码
2. **API Key 安全**：
   - 子账号 API 只勾选「读取 + 下单 + 期货」权限
   - **不要开启提币权限**
   - 设置 IP 白名单，只允许服务器 IP 访问
3. **防火墙配置**：只开放 80、443 端口
4. **定期备份**：开启系统自动备份，每周至少备份一次
5. **HTTPS**：生产环境必须配置 HTTPS
6. **定期更新**：及时更新系统版本，修复安全漏洞
