策略交易系统 v1.2.0
==============================

版本更新日期：2026-08-31

v1.2.0 新增功能：
  - K线自定义拖拽布局（5套预设模板 + 自由拖拽）
  - 用户独立布局存储（每个用户布局互不串用）
  - 公开行情模式（无需绑定子账号即可看K线）
  - 周期价格顶部展示（多周期高低价一行展示）
  - 大单弹窗提醒（顶部居中偏左，方形设计）
  - K线时间周期扩展（1分/5分/15分/1h/4h/日线/周线/月线/年线）
  - 双行工具栏布局（周期价格 + 实时价格/时间筛选）

v1.1.0 功能（已包含）：
  - 系统管理模块（健康检测/缓存清理/备份恢复/版本更新）
  - 新闻AI策略（新闻情绪评分驱动交易信号）
  - EMV V7 策略第10层补全（滚动胜率观察期）
  - 回测引擎支持 EMV V7
  - APScheduler 定时任务兜底（不依赖Celery）
