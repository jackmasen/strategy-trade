1. 环境准备与软件安装

1 登录宝塔面板

浏览器访问 http://你的服务器IP:8888，输入账号密码登录宝塔面板。

提示
如果未安装宝塔面板，SSH 登录服务器执行一键安装： 
yum install -y wget && wget -O install.sh https://download.bt.cn/install/install_lts.sh && sh install.sh ed8484bec

2 安装必要软件

在宝塔面板 软件商店 中搜索并安装以下软件：

软件名称推荐版本用途
Nginx1.24+反向代理 + 前端静态资源
MySQL5.7 或 8.0数据库
Redis6.0+缓存 + 定时任务（APScheduler 兜底）
Python 项目管理器3.10+Python 虚拟环境管理
Supervisor 管理器最新进程守护（自动重启后端）
注意
不需要安装 Node.js，前端可以在本地构建后上传 dist 目录。如果想在服务器上构建，可以在宝塔软件商店安装 Node.js 版本管理器（Node 18+）。

2. 上传项目代码

1 创建网站目录

在宝塔面板 网站 → 添加站点：

  • 域名：填写你的域名或服务器IP
  • 根目录：/www/wwwroot/strategy-trade
  • PHP版本：纯静态
  • 数据库：MySQL（也可选不创建，后面手动建）

2 上传项目文件

将本地项目 strategy-trade-v1.2.0 目录下的所有文件上传到服务器的 /www/wwwroot/strategy-trade/。

上传方式
方式一（推荐）：本地压缩为 zip → 宝塔文件管理上传 → 在线解压
方式二：使用 SCP/SFTP 工具（WinSCP / FileZilla）直接上传

上传后目录结构应为：

/www/wwwroot/strategy-trade/
├── main.py                 # FastAPI 入口
├── .env                    # 环境变量配置
├── requirements.txt        # Python 依赖
├── backend/                # 后端代码
│   ├── config.py
│   ├── core/
│   ├── models/
│   ├── routers/
│   ├── services/
│   └── ...
├── frontend/               # 前端源码
│   ├── src/
│   ├── dist/               # 构建产物（上传此目录即可）
│   └── package.json
├── static/                 # 静态文件（监控页面等）
│   └── monitor-dashboard.html
├── data/                   # SQLite 数据库（兜底用）
├── logs/                   # 日志目录
└── deploy/                 # 部署配置
    ├── nginx.conf
    ├── supervisor.conf
    └── init.sql

3 设置目录权限

在宝塔文件管理器中，右键 /www/wwwroot/strategy-trade → 权限 → 设置为 755，所有者 www。

或 SSH 执行：

chown -R www:www /www/wwwroot/strategy-trade
chmod -R 755 /www/wwwroot/strategy-trade
mkdir -p /www/wwwroot/strategy-trade/logs
mkdir -p /www/wwwroot/strategy-trade/data
chown -R www:www /www/wwwroot/strategy-trade/logs /www/wwwroot/strategy-trade/data

3. 创建 MySQL 数据库

1 宝塔面板创建数据库

宝塔面板 → 数据库 → 添加数据库：

数据库名trading_system
用户名trading_user
密码自己设置一个强密码（记下来，后面要填）
访问权限本地服务器
字符集utf8mb4

2 初始化数据库表

数据库表会在后端首次启动时由 SQLAlchemy 自动创建，无需手动执行 SQL。

说明
首次启动会自动建表并写入初始数据：
超级管理员：admin / Admin@2024
运营账号：trader / Trader@2024

4. 配置 Python 环境

1 创建虚拟环境

打开宝塔 Python 项目管理器 → 添加项目：

项目名称strategy-trade
路径/www/wwwroot/strategy-trade
Python 版本3.10 或 3.11
框架FastAPI
安装方式选择 requirements.txt
启动文件main.py
端口8000

点击确定，等待 Python 环境和依赖包自动安装完成。

2 手动安装依赖（备选）

如果 Python 项目管理器未自动安装依赖，SSH 手动执行：

# 进入项目目录
cd /www/wwwroot/strategy-trade

# 创建虚拟环境（宝塔 Python 项目管理器创建的路径可能不同）
python3.10 -m venv venv

# 激活虚拟环境
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 如果安装慢，使用国内镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

5. 配置 .env 环境变量

1 编辑 .env 文件

在宝塔文件管理器中编辑 /www/wwwroot/strategy-trade/.env：

# ========== 基础配置 ==========
APP_NAME=TradingStrategySystem
APP_ENV=production
APP_DEBUG=false
APP_SECRET_KEY=改成你的随机密钥_用字母数字混合32位以上
API_PREFIX=/api/v1

# ========== 服务端口 ==========
SERVER_HOST=127.0.0.1
SERVER_PORT=8000

# ========== MySQL 数据库 ==========
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=trading_user
DB_PASSWORD=你在第3步设置的数据库密码
DB_NAME=trading_system
DB_CHARSET=utf8mb4
DB_SQLITE_FALLBACK=

# ========== Redis ==========
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=你的Redis密码（宝塔安装时设置的）
REDIS_DB=0
REDIS_DB_CELERY=1

# ========== JWT 认证 ==========
JWT_ALGORITHM=HS256
JWT_ACCESS_TOKEN_EXPIRE_MINUTES=1440
JWT_REFRESH_TOKEN_EXPIRE_DAYS=7

# ========== 币安交易所 ==========
BINANCE_MAIN_API_KEY=
BINANCE_MAIN_API_SECRET=
BINANCE_TESTNET=true
BINANCE_BASE_URL=https://testnet.binancefuture.com

# ========== OKX 交易所 ==========
OKX_MAIN_API_KEY=
OKX_MAIN_API_SECRET=
OKX_MAIN_PASSPHRASE=
OKX_TESTNET=true
OKX_BASE_URL=https://www.okx.com

# ========== AI 接口 ==========
AI_PROVIDER=custom
AI_API_KEY=
AI_API_ENDPOINT=
AI_MODEL_NAME=gpt-4o

# ========== 调度器 ==========
CELERY_ENABLED=false

# ========== CORS ==========
CORS_ALLOW_ORIGINS=https://你的域名

# ========== 风控默认参数 ==========
DEFAULT_MAX_SINGLE_DRAWDOWN=2.0
DEFAULT_DAILY_MAX_LOSS=5.0
DEFAULT_MAX_POSITION_COUNT=3
DEFAULT_TOTAL_POSITION_RATIO=50.0
DEFAULT_SCORE_THRESHOLD=5.0
DEFAULT_LEVERAGE_MIN=3
DEFAULT_LEVERAGE_MAX=10
重要安全提示
首次部署后立即修改默认密码！登录系统后到「个人设置」修改 admin 和 trader 的默认密码。
APP_SECRET_KEY 必须修改为随机字符串，否则 JWT 令牌不安全。

6. 构建前端

1 本地构建（推荐）

在本地开发机器上执行：

cd frontend
npm install
npm run build

构建完成后，将 frontend/dist 目录上传到服务器：

/www/wwwroot/strategy-trade/dist/
├── index.html
└── assets/
    ├── index-xxx.js
    ├── index-xxx.css
    └── ...

2 服务器构建（备选）

如果服务器已安装 Node.js：

cd /www/wwwroot/strategy-trade/frontend
npm install
npm run build
提示
服务器构建需要 1GB 以上内存，小内存服务器建议本地构建后上传。

7. 配置宝塔网站与 Nginx

1 修改网站配置

宝塔面板 → 网站 → 找到你的站点 → 设置 → 配置文件，替换为以下内容：

# 策略交易系统 - Nginx 配置
# 将 your_domain.com 替换为实际域名或IP

server {
    listen 80;
    server_name your_domain.com;

    # 前端静态资源
    root /www/wwwroot/strategy-trade/dist;
    index index.html;

    access_log  /www/wwwlogs/strategy_trade_access.log;
    error_log   /www/wwwlogs/strategy_trade_error.log;

    # 前端 SPA 路由回退
    location / {
        try_files $uri $uri/ /index.html;
        # 静态资源缓存
        location ~* \.(?:js|css|woff2?|ttf|eot|svg|png|jpe?g|gif|ico|webp)$ {
            expires 7d;
            add_header Cache-Control "public, immutable";
        }
    }

    # 后端 API 反向代理
    location /api/ {
        proxy_pass         http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        # WebSocket 支持
        proxy_set_header   Upgrade           $http_upgrade;
        proxy_set_header   Connection        "upgrade";
        # 超时（回测等长时间请求）
        proxy_read_timeout  600s;
        proxy_send_timeout  600s;
        proxy_connect_timeout 60s;
        # SSE 支持（AI控制中心实时推送）
        proxy_buffering    off;
    }

    # API 文档
    location /docs {
        proxy_pass         http://127.0.0.1:8000/docs;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
    }
    location /openapi.json {
        proxy_pass         http://127.0.0.1:8000/openapi.json;
        proxy_set_header   Host              $host;
    }

    # 安全头
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # 禁止访问敏感文件
    location ~ /\.(env|git|svn|ht|installed|gitignore) {
        deny all;
        return 404;
    }
}

保存后，宝塔会自动重载 Nginx。

8. 配置进程守护（Supervisor）

1 添加 Supervisor 守护进程

宝塔面板 → Supervisor 管理器 → 添加守护进程：

名称strategy-trade-api
启动用户www
运行目录/www/wwwroot/strategy-trade
启动命令下方命令

启动命令（根据虚拟环境路径调整）：

/www/wwwroot/strategy-trade/venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000 --workers 2 --log-level info
虚拟环境路径
如果使用宝塔 Python 项目管理器创建的虚拟环境，路径可能是：
/www/server/pyproject_env/strategy-trade_venv/bin/uvicorn
在 SSH 中执行 which uvicorn 或检查 Python 项目管理器中的环境路径来确认。

环境变量设置：

PYTHONUNBUFFERED=1
ENV_FOR_DYNACONF=production

2 手动配置 Supervisor（备选）

如果使用命令行操作，创建配置文件：

cat > /etc/supervisord.d/strategy-trade.ini << 'EOF'
[program:strategy-trade-api]
directory=/www/wwwroot/strategy-trade
command=/www/wwwroot/strategy-trade/venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000 --workers 2 --log-level info
environment=
    PYTHONUNBUFFERED="1",
    ENV_FOR_DYNACONF="production"

user=www
autostart=true
autorestart=true
startsecs=5
startretries=3
stopasgroup=true
killasgroup=true
redirect_stderr=false
stdout_logfile=/www/wwwroot/strategy-trade/logs/api.log
stdout_logfile_maxbytes=50MB
stdout_logfile_backups=10
stderr_logfile=/www/wwwroot/strategy-trade/logs/api_error.log
stderr_logfile_maxbytes=50MB
stderr_logfile_backups=10
EOF

supervisorctl reread
supervisorctl update
supervisorctl start strategy-trade-api

9. 申请 SSL 证书

1 申请 Let's Encrypt 免费证书

宝塔面板 → 网站 → 你的站点 → SSL → Let's Encrypt：

  1. 勾选你的域名
  2. 点击「申请」
  3. 申请成功后开启「强制 HTTPS」
提示
SSL 申请需要域名已解析到服务器IP，且 80 端口可访问。

2 修改 .env 启用 HTTPS

# 修改 CORS 为 HTTPS 域名
CORS_ALLOW_ORIGINS=https://你的域名

修改后重启后端进程：

supervisorctl restart strategy-trade-api

10. 防火墙与安全设置

1 放行端口

宝塔面板 → 安全：

端口方向用途
80入站HTTP（Nginx）
443入站HTTPS（Nginx）
8888入站宝塔面板（建议改默认端口）
安全警告
不要放行 8000 端口！后端只通过 Nginx 反向代理访问，不直接暴露。

2 云服务器安全组

如果使用阿里云/腾讯云/AWS 等，还需在云控制台的安全组中放行 80 和 443 端口。

12. 常见问题排查

Q1: 后端启动报错 ModuleNotFoundError

虚拟环境中依赖未安装完整，执行：

cd /www/wwwroot/strategy-trade
source venv/bin/activate
pip install -r requirements.txt

Q2: 数据库连接失败

检查 .env 中 DB_* 配置是否正确：

# SSH 测试 MySQL 连接
mysql -u trading_user -p -h 127.0.0.1 trading_system

检查 MySQL 是否运行：宝塔面板 → 软件商店 → MySQL → 状态。

Q3: Redis 连接失败

系统会在 Redis 不可用时自动降级为 APScheduler 内存调度，不影响基本运行。如需启用 Redis：

# 检查 Redis 状态
redis-cli ping
# 应返回 PONG

# 如果有密码
redis-cli -a 你的密码 ping

Q4: 前端页面白屏

检查 dist 目录是否正确上传：

ls /www/wwwroot/strategy-trade/dist/
# 应看到 index.html 和 assets/ 目录

检查 Nginx 配置中 root 路径是否正确指向 dist 目录。

Q5: API 502 Bad Gateway

后端进程未运行或端口不对。检查：

# 检查后端进程状态
supervisorctl status strategy-trade-api

# 检查端口监听
netstat -tlnp | grep 8000

# 查看后端错误日志
tail -50 /www/wwwroot/strategy-trade/logs/api_error.log

Q6: WebSocket / SSE 连接失败

Nginx 反向代理需要配置 WebSocket 支持，确认配置中有：

proxy_set_header   Upgrade           $http_upgrade;
proxy_set_header   Connection        "upgrade";
proxy_buffering    off;

Q7: 定时任务不执行

确认 .env 中 CELERY_ENABLED=false（默认），系统使用内置 APScheduler 自动运行：

  • 持仓检查：每 30 秒
  • 策略执行：每 1 分钟
  • 新闻采集：每 30 分钟
  • AI 分析：每 2 小时

查看后端日志确认任务运行：

tail -100 /www/wwwroot/strategy-trade/logs/api.log | grep -i scheduler

Q8: 修改 .env 后不生效

修改环境变量后必须重启后端进程：

supervisorctl restart strategy-trade-api

Q9: 日志目录权限问题

mkdir -p /www/wwwroot/strategy-trade/logs
chown -R www:www /www/wwwroot/strategy-trade/logs
chmod 755 /www/wwwroot/strategy-trade/logs

Q10: 服务器内存不足（1G 以下）

小内存服务器建议：

  • uvicorn workers 改为 1：--workers 1
  • 使用本地构建前端，不在服务器上 npm build
  • 添加 Swap 分区：宝塔面板 → 工具 → Linux工具箱 → Swap
