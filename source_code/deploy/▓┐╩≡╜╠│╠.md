## 三、路径 A：宝塔 Linux 生产部署（最稳，强烈推荐单机生产）

### Step A-0 环境准备
宝塔面板版本：7.x / 9.x 皆可。宝塔软件商店已安装：
1. Nginx 1.20+
2. MySQL 5.7 / 8.0（任选）
3. Redis 6.0+
4. Supervisor 管理器（软件商店 → 搜索安装 Supervisor
5. Node.js 18+（在「网站 → Node 版本管理器
6. Python 3.10+（在「网站 → Python项目管理器」或编译安装 / 或 apt/yum 装到 /usr/bin/python3.10+
7. （若用默认 3.9 也行；3.10 更好

### Step A-1 上传代码到服务器
把你从桌面拿到的 `strategy-trade.zip 解压到 **/www/wwwroot/strategy-trade**

```bash

cd /www/wwwroot/strategy-trade
# 给执行权限
chmod +x deploy/install.sh deploy/upgrade.sh
```

### Step A-2 创建 MySQL 数据库 + 用户（宝塔面板）
- 宝塔 → 数据库 → 添加数据库
  - 库名：`trading_system
  - 用户名：`trading_user
  - 密码：自己设一个强密码（记下来要配到 `.env）
  - 访问权限：本地服务器 127.0.0.1
- 字符集：`utf8mb4

> 说明：**表结构不用手动导入 SQL，系统启动 FastAPI 的 lifespan 会自动建表 + 初始化种子管理员 admin/Admin@2024。

### Step A-3 配置环境变量（核心）
拷贝环境变量：

**必须填的 10 项（照着填就行：

```env
# ④ 币安/OKX 至少填一个，另一个留空不启用
```

## 五、路径 C：Docker Compose 一键（可选，容器爱好者）
在服务器新建 `docker-compose.yml`（示例）

```yaml
version: "3.9"
services:
  mysql:
    image: mysql:8.0
    command: --default-authentication-plugin=mysql_native_password --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci
    environment:
      MYSQL_ROOT_PASSWORD: Root_123456
      MYSQL_DATABASE: trading_system
      MYSQL_USER: trading_user
      MYSQL_PASSWORD: DbPass_123456
    ports: ["3306:3306"]
    volumes: [mysql_data:/var/lib/mysql]
    restart: unless-stopped

  redis:
    image: redis:7-alpine
    command: redis-server --requirepass RedisPass_123456 --appendonly yes
    ports: ["6379:6379"]
    volumes: [redis_data:/data]
    restart: unless-stopped

  backend:
    build:
      context: .
      dockerfile: deploy/Dockerfile.backend
    environment: &env
      APP_SECRET_KEY: DevChangeMeRandom32CharsOrMore
      DB_HOST: mysql
      DB_PORT: 3306
      DB_USER: trading_user
      DB_PASSWORD: DbPass_123456
      DB_NAME: trading_system
      REDIS_HOST: redis
      REDIS_PORT: 6379
      REDIS_PASSWORD: RedisPass_123456
      BINANCE_TESTNET: "true"
    depends_on: [mysql, redis]
    ports: ["8000:8000"]
    restart: unless-stopped

  celery-worker: &celery-base
    <<: *celery-base
    command: celery -A backend.core.celery_app worker -l info -Q scoring,risk,news,report,default
    depends_on: [mysql, redis]
    restart: unless-stopped

  celery-beat:
    <<: *celery-base
    command: celery -A backend.core.celery_app beat -l info --max-interval 300
    depends_on: [mysql, redis]
    restart: unless-stopped

  frontend:
    image: nginx:alpine
    volumes:
      - ./frontend/dist:/usr/share/nginx/html:ro
      - ./deploy/frontend-nginx.conf:/etc/nginx/conf.d/default.conf:ro
    ports: ["8080:80"]
    depends_on: [backend]
    restart: unless-stopped

volumes:
  mysql_data:
  redis_data:
```

启动：
```bash
docker compose up -d --build
```
