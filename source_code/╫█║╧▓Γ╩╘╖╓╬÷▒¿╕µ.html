✅ 一、系统修复清单

✅
CrawlerHealth.vue 动态导入错误 (P0级)
根因：JS语法错误 — 空值合并运算符(??)与逻辑或(||)不能混用，需加括号。Vite编译失败导致动态import 404。修复：data.xray_available ?? data.installed → (data.xray_available ?? data.installed) || false
✅
回测引擎0交易问题 (P0级)
根因1：SMA索引对齐错误，prev_s = sma_short[i-26]应为sma_short[i-7]。根因2：K线时间戳解析使用了不存在的timestamp字段，应为open_time_ms。修复后从0交易恢复为68-267笔交易。
✅
Xray状态不同步 (P1级)
根因：API返回xray_available字段，前端检查data.installed。修复：统一使用 (data.xray_available ?? data.installed) 判断安装状态。
✅
快速切换页面报错 (P1级)
根因：组件卸载后异步请求仍执行。修复：开发useSafeRequest组合式函数，使用AbortController在组件卸载时取消所有请求和定时器；添加Vue errorHandler过滤无害错误。
✅
ResizeObserver错误弹窗 (P1级)
根因：ECharts/Element Plus布局变化触发ResizeObserver循环错误。修复：在全局错误处理器中添加ResizeObserver过滤，忽略该类无害错误。
✅
权益曲线MaxDD=0 (P2级)
根因：权益曲线在交易结束后用最终资金构建，未反映过程波动。修复：从交易记录逐笔计算权益变化，重建权益曲线。
✅
EMV策略capital未初始化 (P2级)
根因：EMV策略分支未初始化capital变量，且只扣手续费不扣保证金。修复：添加capital = initial_capital初始化，修改为capital -= (margin + fee)。
✅
策略硬编码参数 (P2级)
根因：杠杆(3x)、止损(5%)等参数硬编码，未使用策略配置。修复：从_params动态读取leverage_fixed、sl_ratio等参数。
✅
Xray自动安装与集成 (P2级)
实现Xray-core自动下载安装、VLESS/VMess/Trojan/SS协议解析、本地SOCKS5端口转换(20000-20099)、10分钟健康检查、与爬虫代理池自动集成。
✅
爬虫健康检测面板 (P3级)
新增15个新闻爬虫的24h/7d采集量监控、状态指示灯(绿=正常/黄=异常/红=被屏蔽)、代理池配置和健康检查、节点实时检测功能。

💡 六、优化建议与运营方案

推荐运营方案

  • 主策略：策略2（平衡型）- TP 4% / SL 2% / 杠杆 3-8x
  • 周期：4h K线 - 交易频率适中(68-216笔/年)，信噪比高
  • 币种：BTC + ETH + SOL 三币种分散 - 年化+8.91%
  • 仓位：单仓10%总仓50% - 控制风险
  • 避免：15m和1h周期 - 交易过度频繁，手续费侵蚀利润
[高优先级]
1. 配置AI分析API (当前离线模式)
AI分析权重占30%但当前默认5.0分，需配置OpenAI/Claude API。预期效果：预测置信度从39%提升至65%+，策略评分更准确，开仓质量提升。配置路径：系统设置 → AI分析 → 填入API Key。
[高优先级]
2. 接入Polymarket预测数据
预测模型中10%的Polymarket权重未生效（当前null）。接入后可将预测准确率提升5-10%。需开发Polymarket API接入，获取加密货币价格预测市场的概率数据。
[高优先级]
3. 修复Strategy 8高杠杆档位异常
策略8的高分杠杆上限leverage_high_score=5，与中分相同，应为8。需调整策略配置：leverage_high_score从5改为8，使高分信号获得更高杠杆。
[中优先级]
4. 增加布林带/MACD背离策略
当前仅有MA金叉死叉+RSI过滤和EMV两种策略类型。增加布林带突破和MACD背离策略可丰富策略组合，在不同市场行情下获得更好收益。
[中优先级]
5. 添加滑点模型优化
当前滑点固定0.05%，大单交易实际滑点更高。建议根据订单大小动态计算滑点：滑点 = 基础0.03% + 订单金额/流动性 * 0.02%，更贴近实际交易。
[中优先级]
6. 优化SOL预测稳定性
SOL预测方向在neutral/bullish间频繁波动，置信度仅38.9%。建议增加置信度阈值：当confidence < 45%时输出neutral而非bullish，避免误导开仓决策。
[低优先级]
7. 回测引擎增加手续费阶梯
当前手续费固定0.04%，实际交易所maker/taker费率不同。建议支持阶梯费率配置：maker 0.02%，taker 0.05%，VIP阶梯递减。
[低优先级]
8. 增加回测walk-forward分析
当前回测为全量历史回测，可能过拟合。建议增加walk-forward分析：将历史数据分为训练期和测试期，滚动验证策略稳健性。
