================================================================

▶️ 你现在要解决的问题：http://127.0.0.1:8000/docs 访问不到
   根因 1：后端进程没有启动（8000 端口完全没监听）
   根因 2：即使后端启动了，之前的代码把 /docs 绑在了「调试模式」下，导致生产模式看不到 Swagger
         👉 本版本已修复！main.py 强制把 /docs 挂在根路径，启动即能看到。

第一次使用本机（以后都不用再做 Step 1）：

🐛 常见报错 & 解决（1 分钟解决）
================================================================
  1) 访问 /docs 看到「127.0.0.1 拒绝了我们的连接请求」
     → 后端没启动，重新执行 Step2，等后端窗口出现 Uvicorn running。

  2) 启动后端窗口里一堆 MySQL 连接错误 / Access denied
     → 还没装 MySQL 或还没配置连接串：完全 OK，系统自动用 SQLite
       （文件：项目根/trading_system.db），/docs 和所有功能不影响。
       想切回 MySQL：改项目根/.env（或复制 .env.example 为 .env，填 DB_* 配置）。

  3) Step3 启动前端提示「node 未找到」
     → 装 Node.js 18+（https://nodejs.org/，安装时勾 Add to PATH，装完重启电脑）。
     → 或者先直接打开 preview\index.html 看静态 UI 骨架。

  4) 8000 端口被占用：
     cmd 里跑：
       netstat -ano | findstr :8000
       taskkill /PID <PID号> /F
     然后重新执行 Step2。

  5) 想把启动器放桌面方便点：
     双击「0_把启动器复制到桌面.bat」即可，桌面会得到 StrategyTradeLauncher 文件夹。
