🛠 问题一：本地 http://127.0.0.1:8000/health 无法访问 👉 一键启动后端（1 次双击即可）

你的系统开启了严格的「PowerShell ExecutionPolicy + 脚本限制策略」，.bat/.vbs/.ps1 会被拦截。✅ 已解决 使用 Windows 原生 mshta.exe 启动器，不经过任何脚本限制，直接创建进程启动 python.exe。

▶️ 一键启动后端 · 自动打开 /docs（HTA 启动器） 🖤 备用方案 A · Python 无黑框版 💻 备用方案 B · Python 有控制台版

✅ 2 个「后端已启动成功」强信号（任一出现即可）

浏览器自动弹出并打开 http://127.0.0.1:8000/docs，能看到 Swagger UI（左侧一长串接口列表 + Authorize 按钮）
启动器底部状态显示：✅ /health 返回 200，已自动打开浏览器

❌ 若仍未成功，请查看这两份日志（99% 问题都在里面）

启动过程日志 _logs_backend_launcher.log：记录查找 Python、建 venv、装依赖、杀 8000、启 uvicorn 的每一步
后端运行日志 _logs_backend.log：uvicorn 的 stdout/stderr，包括 DB 建表、种子初始化、路由注册、启动错误堆栈

🪜 备用方案 C · 3 行 cmd 手敲（极端兜底）

  1. Win + R → 输入 cmd → 回车打开黑框
  2. 粘贴执行：cd /d "%USERPROFILE%\Desktop\StrategyTradeLauncher"（或 cd 到项目根）
  3. 依次执行下面 3 行（首次会久一点，耐心等 pip 安装完）

最后一行黑框显示 Uvicorn running on http://0.0.0.0:8000 后，手动打开 http://127.0.0.1:8000/docs

🏢 问题二：这个系统支持宝塔安装搭建吗？ 👉 100% 支持，以下是宝塔 Linux 快速教程

生产推荐 本项目原生支持 宝塔面板 Linux 一键部署（CentOS / Ubuntu / Debian 皆可），完整教程在：deploy/部署教程.md。下面给出 7 步快速摘要，你照做即可上线。

  1. Step 0 · 宝塔软件商店先安装这 6 个（搜索一键安装即可）： Nginx 1.20+ MySQL 5.7/8.0 Redis 6.0+ Supervisor Node 18+（Node 版本管理器） Python 3.10+（Python 项目管理器）
  2. Step 1 · 上传代码：把项目 zip 解压到服务器 /www/wwwroot/strategy-trade，然后宝塔终端执行：
    cd /www/wwwroot/strategy-trade
    chmod +x deploy/install.sh deploy/upgrade.sh
  3. Step 2 · 宝塔面板建 MySQL 数据库：
    库名：trading_system，用户名：trading_user，密码：你自己的强密码，权限：127.0.0.1，字符集 utf8mb4
    👉 不用手动导 SQL！FastAPI lifespan 启动时会自动建表 + 初始化种子管理员 admin / Admin@2024，上线后请立刻到「个人中心」改密码。
  4. Step 3 · 配置 .env（10 项必填）：
    cp .env.example .env
    chmod 600 .env
    vi .env
    # ① APP_SECRET_KEY=32位随机串
    # ② DB_HOST=127.0.0.1 / DB_PORT=3306 / DB_USER=trading_user / DB_PASSWORD=刚才的密码 / DB_NAME=trading_system / DB_CHARSET=utf8mb4 / DB_SQLITE_FALLBACK=
    # ③ REDIS_HOST=127.0.0.1 / REDIS_PORT=6379 / REDIS_PASSWORD=宝塔Redis密码（无则空）/ REDIS_DB=0 / REDIS_DB_CELERY=1
    # ④ BINANCE_* 或 OKX_* 至少填一组子账号 API（另一组留空 = 不启用）
    # ⑤ PROXY_ENABLED=true / PROXY_HTTP_LIST=http://你的代理地址1,http://代理地址2（新闻抓不到再填）
    # ⑥ 风控：DEFAULT_MAX_SINGLE_DRAWDOWN=1.5 单笔最大 1.5%（上线前按资金体量调小一点）
  5. Step 4 · 一键跑 install.sh（自动建 venv / 装 pip 依赖 / npm install / npm run build 前端）：
    bash deploy/install.sh
  6. Step 5 · 宝塔「Supervisor 管理器」添加 3 个守护进程（后端 API + Celery Worker + Celery Beat 定时任务）：
    项目名启动用户启动命令运行目录
    strategy-backendwww/www/wwwroot/strategy-trade/.venv/bin/python -m uvicorn main:app --host 127.0.0.1 --port 8000 --log-file logs/uvicorn.log/www/wwwroot/strategy-trade
    strategy-celery-workerwww/www/wwwroot/strategy-trade/.venv/bin/celery -A backend.core.celery_app.celery worker -l info -Q default --concurrency=2/www/wwwroot/strategy-trade
    strategy-celery-beatwww/www/wwwroot/strategy-trade/.venv/bin/celery -A backend.core.celery_app.celery beat -l info --pidfile=logs/celerybeat.pid --scheduler django_celery_beat.schedulers:DatabaseScheduler/www/wwwroot/strategy-trade
  7. Step 6 · 宝塔「网站」→ 添加站点 / Nginx 配置：
    域名填你的域名或服务器 IP，根目录指向 /www/wwwroot/strategy-trade/frontend/dist，PHP 版本选 纯静态。
    然后在站点设置 → 配置文件 → 插入反向代理 /api 到 8000（完整配置示例已在 deploy/nginx.conf）：
    location /api/ {
      proxy_pass http://127.0.0.1:8000;
      proxy_set_header Host $host;
      proxy_set_header X-Real-IP $remote_addr;
      proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
      proxy_set_header X-Forwarded-Proto $scheme;
      proxy_read_timeout 300s;
      # WebSocket 升级头（币安/OKX 行情推送需要）
      proxy_http_version 1.1;
      proxy_set_header Upgrade $http_upgrade;
      proxy_set_header Connection "upgrade";
    }
    location /docs { proxy_pass http://127.0.0.1:8000/docs; }
    location /redoc { proxy_pass http://127.0.0.1:8000/redoc; }
    location /openapi.json { proxy_pass http://127.0.0.1:8000/openapi.json; }
    location /health { proxy_pass http://127.0.0.1:8000/health; }

    👉 保存重载 Nginx 后，访问 https://你的域名/ 即可看到前端；访问 https://你的域名/docs 看到 Swagger UI；访问 https://你的域名/health 看到 status=ok 就代表部署完成 🎉 最后记得登录后去「个人中心」修改默认密码 Admin@2024。

后端入口 main.py 已将 /docs · /redoc · /openapi.json · /health 无条件挂在根路径（不依赖 API_PREFIX / debug），生产环境一定能访问。
遇到问题：优先看日志 项目根/_logs_backend.log（本地）或 /www/wwwroot/strategy-trade/logs/（宝塔生产）。
