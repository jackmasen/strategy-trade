⚠️ 后端还没启动（WordPress 式体验差最后 1 步）

你已经完成了宝塔建站 + 上传源码 + 点击域名。现在就差启动一下 Python 后端（和 WordPress 区别：WordPress 是 PHP 默认 Nginx 就带了；Python 需要自己起一个 uvicorn 进程）。

最简单：1 条命令（强烈推荐 ⭐）

宝塔左侧菜单 → 终端（或点击站点 → 终端按钮），粘贴下面这一行回车即可：

cd /www/wwwroot/$(ls -t /www/wwwroot | head -1) 2>/dev/null || cd /www/wwwroot/*/ ; test -f deploy/onepress-install.sh && bash deploy/onepress-install.sh
📌 不想打字？用宝塔「Python 项目管理器」GUI 填值（点我展开）

宝塔软件商店安装「Python 项目管理器」，然后添加项目，按下面填：

字段填什么
项目名称strategy-trade
项目路径/www/wwwroot/你的站点目录
Python 版本3.10 / 3.11 / 3.12 任意（没有就先装）
框架FastAPI / uvicorn
启动方式模块方式：uvicorn main:app --host 127.0.0.1 --port 8000 --log-file logs/uvicorn.log
安装依赖✅ 勾选
启动用户www
🧭 不知道站点根路径在哪里？（点我看 5 秒怎么找）
  1. 宝塔左侧菜单 → 网站 → 找到你刚才加的站点一行
  2. 点击 根目录 四个字 → 弹出文件管理器，顶部路径栏就是站点根（例如 /www/wwwroot/trade.xxx.com）
  3. 把上面 1 行启动命令 的 /www/wwwroot/*/ 换成你的实际路径，更稳；但一般直接粘贴自动通配符也能定位到
📝 你粘贴回车后，命令会自动做什么？
  1. 自动找 Python 3.10+（含宝塔 pyenv 的）
  2. 创建 .venv 虚拟环境
  3. 用清华镜像 pip install -r requirements.txt（失败自动退回官方源）
  4. 清理旧 uvicorn 进程（若存在）→ nohup 后台启动 uvicorn 127.0.0.1:8000，日志写到 logs/uvicorn.log
  5. 等 4 秒后探测 /health，打印成功提示

看到终端输出 /health 探测返回 200 就表示后端启动成功。

后端起来后，页面会自动变成绿色「✅ 后端已经跑起来了」的按钮，直接点进 /install 即可。

② 当前目录解压完整性自检 自检中...

下面这几个关键文件必须存在，不存在就说明 zip 解压错了（嵌在二级目录里了）：

    ✅ 解压正确，main.py 在站点根目录。
    ❌ 解压错误：main.py / deploy / backend 不在站点根。
    解决：打开宝塔文件管理器，你会看到一个二级文件夹（比如 strategy-trade-onepress-v1.0.0-xxx/），进入这个二级文件夹 → 全选所有文件/目录 → 剪切 → 回站点根 → 粘贴，然后刷新本页。

    ③ 后端起来后，/install 向导会做什么？

    3.1 环境预检

    • Python 版本（≥ 3.10）
    • 磁盘 ≥ 5 GB
    • 内存
    • MySQL / SQLite 连接测试
    • Redis 连接（不通也能跑，只是不开 Celery）
    • 缺失的 Py 包清单（会告诉你缺什么）
    • frontend/dist 是否已构建

    3.2 安装配置（就像 WordPress wp-config.php）

    • 管理员账号密码（自定义，不强制 admin/Admin@2024，长度≥8 + 字母+数字）
    • APP_SECRET_KEY（留空自动生成 64 位）
    • ✅ 勾选 SQLite（强烈推荐第一次用，不用建库！）
    • MySQL / Redis / 币安 / OKX / 代理 / AI 模型（都可留空，装好再改）
    • 点击【▶️ 运行安装】2~5 秒即可
    3.3 一键输出部署配置
    安装完成后第 ③ 步会直接输出：
    • 📋 宝塔「Python 项目管理器」字段填充值表
    • 📋 1 行后台启动命令（nohup uvicorn）
    • 📋 Nginx 反代片段（站点设置 → 配置文件里直接粘贴）

    复制三份里任意一份 + 贴 Nginx 片段就全部完成。

    ✅ 最后验收 3 个信号（Famous 5 秒结束）

    1. 访问 /health → 返回 {"status":"ok","installed":true}
    2. 访问 /docs → Swagger UI，POST /api/v1/auth/login 用你刚才填的管理员账号密码，返回里有 access_token
    3. 访问 / → 前端登录页正常（没构建 dist 时是引导页，也算 OK，/docs 能用就行）
