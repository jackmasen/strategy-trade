# 策略交易系统 v1.2.6 - 宝塔面板升级指南

## 升级步骤

### 方式一：使用自动升级脚本（推荐）

1. **上传文件到服务器**
   - 将桌面上的 `strategy-trade-v1.2.6-update.zip` 上传到服务器
   - 将 `deploy/deploy_v1.2.6.sh` 上传到 `deploy/` 目录

2. **SSH 登录服务器，执行以下命令：**
   ```bash
   # 进入项目目录
   cd /www/wwwroot/strategy-trade
   
   # 停止旧服务
   supervisorctl stop all
   
   # 解压新源码（覆盖原文件，保留 .env）
   unzip -q ~/strategy-trade-v1.2.6-update.zip -d /tmp/st-update
   rsync -av --exclude='.env' --exclude='venv' --exclude='node_modules' --exclude='dist' /tmp/st-update/strategy-trade-v1.2.4_源码/ /www/wwwroot/strategy-trade/
   rm -rf /tmp/st-update
   
   # 执行升级脚本
   chmod +x deploy/deploy_v1.2.6.sh
   bash deploy/deploy_v1.2.6.sh
   ```

### 方式二：宝塔面板文件管理器

1. 登录宝塔面板 → 文件 → 进入 `/www/wwwroot/`
2. 删除 `strategy-trade` 目录下的所有文件（**保留 .env**）
3. 解压 `strategy-trade-v1.2.6-update.zip` 上传到 `strategy-trade` 目录
4. 在终端执行：
   ```bash
   cd /www/wwwroot/strategy-trade
   bash deploy/deploy_v1.2.6.sh
   ```

## 如果服务器上没有 venv

```bash
# 创建虚拟环境
cd /www/wwwroot/strategy-trade
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cd frontend && npm install && npm run build && cp -r dist .. && cd ..
supervisorctl restart all
```

## 常见问题

**Q: 提示 "externally-managed-environment"**
A: 使用 venv 而不是系统 pip：`source venv/bin/activate && pip install -r requirements.txt`

**Q: 前端构建失败**
A: 确保 Node.js 18+ 已安装：`node --version`

**Q: 后端启动报错 pyotp**
A: `source venv/bin/activate && pip install pyotp==2.9.0`
