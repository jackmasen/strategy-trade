## 四、前端 dist 没一起打进 zip 的原因 + 怎么补？（1 行命令）
我在 TRAE 后台跑 `npm install` 卡在了下载依赖（5 分钟完全没输出，当前网络对 npm 官源慢；node/npm 本身已经找到 v11.16.0 正常）。**两种方式任选其一，几分钟就拿到「含前端完整发布包」**：

### 方式 A（推荐 · 宝塔服务器做）
上传当前 zip → 解压到站点根 → 宝塔终端：
```bash
cd /www/wwwroot/trade.xxx.com/frontend
npm install --no-audit --no-fund --registry=https://registry.npmmirror.com
npm run build
cd ..
bash deploy/onepress-install.sh      # 重启一下后端
```
✅ 好处：国内宝塔服务器对 npmmirror.com 很快，30~60 秒 build 完，/ 就直接是登录页了。

### 方式 B（本机再打一份 zip）
项目根：
```
1) 开 CMD/PowerShell：
   cd frontend
   npm config set registry https://registry.npmmirror.com
   npm install
   npm run build
2) 回到项目根，双击 立即打包_请双击我.pyw（或 0_一键打包_双击我→zip自动出现在桌面.pyw）
   3~10 秒后桌面新 zip 就带 frontend/dist 了。
```
