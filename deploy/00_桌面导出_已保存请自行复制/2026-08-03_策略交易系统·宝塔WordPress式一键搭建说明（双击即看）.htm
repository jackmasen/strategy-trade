🏁 策略交易系统 · 宝塔 WordPress 式一键搭建

像装 WordPress 一样傻瓜：宝塔加网站 → 传 zip → 解压 → 访问域名自动进 /install 向导。Famous 5 分钟
✅ 前置准备（一次性，之前装过就跳过）：
宝塔面板 → 软件商店，确保已经安装： Nginx 任意版本 + Python 项目管理器（或单独装 Python 3.10 / 3.11 / 3.12 任意）。
（MySQL 8.x / 5.7 可选，第一次推荐直接勾选 SQLite 零依赖，不用建库。）

🔹 第一部分：宝塔 4 步把代码跑起来

添加站点（1 分钟）

  • 宝塔左侧菜单 → 网站 → 添加站点
  • 域名：填你的域名，例如 trade.xxx.com（没域名就填服务器公网 IP）
  • 根目录：默认就行，如 /www/wwwroot/trade.xxx.com
  • FTP / 数据库 / PHP：全关—— PHP 选『不创建』，数据库选『不创建』。我们用 Python + FastAPI。
  • 点 提交，站点就建好啦。

上传 onepress zip → 解压（1 分钟）

  • 网站列表里找到刚加的站点，点击 根目录 进入文件管理
  • 点 上传 → 选打包好的 strategy-trade-onepress-v1.0.0-xxxxxxxx.zip
  • 上传完后 右键 zip → 解压到当前目录。解压后 main.py 必须在站点根下，不能嵌在二级目录里！
📌 验证解压对不对：站点根路径下，你应该能直接看到：main.py、requirements.txt、backend/、frontend/、deploy/、.env.example。
如果你看到的是一个二级目录（例如 strategy-trade-onepress-v1.0.0-xxx/main.py），就把二级目录里的所有文件剪切/移动到站根。

启动后端（2 分钟，二选一，推荐 A）

方案 A · 1 行 bash 脚本（最稳，宝塔新手推荐）

点击站点 终端 按钮，或宝塔左侧 终端，进入站点根后粘贴：

cd /www/wwwroot/trade.xxx.com
bash deploy/onepress-install.sh

脚本会自动：找 Python 3.10+ → 建 venv → 清华源 pip install → 后台 nohup 起 uvicorn（端口 8000）→ 探测 /health。

看到最后一行的 /health 探测返回 200 就成功。

方案 B · 宝塔「Python 项目管理器」GUI 启动

适合不想用终端的朋友，全图形化：

字段填什么
项目名称strategy-trade
项目路径/www/wwwroot/trade.xxx.com
Python 版本3.10 / 3.11 / 3.12 任意（没有就先装）
框架FastAPI / uvicorn
启动方式模块方式：uvicorn main:app --host 127.0.0.1 --port 8000 --log-file logs/uvicorn.log
安装依赖✅ 勾选（会自动跑 pip install -r requirements.txt）
启动用户www（避免 root）

贴 Nginx 反代片段（30 秒）

宝塔 → 网站 → 设置 → 配置文件：

  1. 千万不要删掉原有 server { ... } 里的 listen / server_name / ssl_certificate 等行！
  2. 只在 server { 内部、现有 location 之外，粘贴 deploy/onepress-nginx-snippet.conf 里的内容。
  3. 把文件里两处占位路径 /www/wwwroot/trade.xxx.com 改成你实际的站点根。
  4. 保存。

🔹 第二部分：浏览器 /install 向导 3 步（WordPress famous 5 秒安装）

现在访问你的域名：https://trade.xxx.com/（或 http://服务器IP）。
因为还没安装，系统会 自动 307 跳转到 /install，进入漂亮的安装向导。

① 环境预检

向导自动检测：Python 版本 / 磁盘 / 内存 / DB / Redis / 缺失的 Py 包 / requirements.txt 是否存在 / frontend dist 是否构建。

🚀 第一次安装最佳实践：预检表里数据库 ✅ 不通过没关系——下面第 ② 步勾选 先用 SQLite，秒过。Redis 红了也不影响后端启动（后续在系统设置里配）。

看到 ① 里所有检查项之后，点下一步 ▶️ 运行安装。

② 填写配置 & 安装

就像 WordPress 填 wp-config.php 一样：

  • 站点标题 / 运行环境：默认就行
  • 管理员账号：建议改掉默认 admin，例如 boss_zhangsan
  • 管理员密码：至少 8 位，字母 + 数字（加符号更安全）——记得存到密码管理器
  • APP_SECRET_KEY：留空，系统自动生成 64 位（JWT 秘钥，换服务器记得同步）
  • ✅ 勾选 先试用 SQLite（强烈建议首次勾上，省去建 MySQL 的麻烦）
  • Redis 主机 / 密码：没有 Redis 就默认，没关系
  • 更多配置（币安 / OKX / 代理 / AI 模型）：都留空就行，装好以后在前端或 .env 里随时改。

点绿色大按钮 ▶️ 运行安装（写入 .env → 建表 → 创建管理员）——2~5 秒完成。

③ 安装完成，Famous 5 秒结束！复制 2 个配置即可

成功后，/install 第 ③ 步会自动弹出 3 套方案，复制任意一套都行：

方案适合人群做什么
方案 A（宝塔最快） 不想动终端的用户 打开宝塔「Python 项目管理器」→ 按页面表格填 → 启动
方案 B（最推荐 ⭐） 有终端粘贴习惯的，最稳 点击 📋 复制 1 行启动命令 → 宝塔站点根终端粘贴 → 回车
方案 C（反代片段） 所有用户都建议执行 点击 📋 复制 Nginx 反代片段 → 宝塔站点配置文件 server{ } 内粘贴 → 保存
💡 如果你刚才已经在第一部分第 3、4 步执行过启动命令和 Nginx 片段，那这一步就什么都不用再做——直接验收下面 3 个信号。

🔹 常见坑 & FAQ（遇到问题先看这一节）

Q1：访问域名显示 403 Forbidden / 目录列表 / 502 Bad Gateway

90% 的概率是 Nginx 片段没贴 / 贴错位置：
① 重新检查 第二部分第 ③ 步 / 第一部分第 4 步。
② 确认站点根路径和 Nginx 片段里的 /www/wwwroot/trade.xxx.com 完全一致（多一个斜杠都不行）。
③ 502 说明 uvicorn 没起起来：站点根跑 tail -n 200 logs/uvicorn.log 看堆栈，90% 是端口 8000 被占或依赖没装全 → 重跑 bash deploy/onepress-install.sh。

Q2：我想重装（换管理员密码 / 换数据库）

先备份配置：cp -a .env .env.bak.$(date +%s)
然后删除安装标记：rm -f .installed
浏览器重新访问 /install，就会重新进入向导。
（注意：删 .installed 不会自动删数据库；要完全干净，再手动删 trading_system.db 或 DROP MySQL 库。）

Q3：安装向导里我勾了 SQLite，现在想切 MySQL

① 宝塔建一个 MySQL 数据库（utf8mb4），记好 host/port/user/pass/dbname。
② 直接用向导生成的 .env：把 DB_SQLITE_FALLBACK= 那行清空、下面 MySQL 6 行填上。
③ 重启 uvicorn（kill $(cat logs/uvicorn.pid) ; bash deploy/onepress-install.sh）。
④ 第一次启动会自动 CREATE TABLE，管理员账号要重建（因为你换了 DB）；不想重建就把 SQLite 的库用 DBeaver 迁过去。

Q4：Celery / Redis 要不要现在开？

最小可用不用：策略模板、回测、手动下单都能跑。
要开 AI 新闻推送 / 定时策略 / 心跳告警：再开 Redis + 跑 deploy/supervisor.conf 里的 3 个进程（uvicorn / celery worker / celery beat）。

Q5：本地 Windows 也要像这样一键跑？

解压 zip 后双击 StrategyTradeLauncher/Step0_一键启动后端_8000_HTA启动器.hta 即可（绕过 ExecutionPolicy / AppLocker）。浏览器自动跳 http://127.0.0.1:8000/install 也是同样的 WordPress 式体验。

🔹 速查命令卡（宝塔终端里随时复制执行）

# 站点根（请改成你的真实路径）
cd /www/wwwroot/trade.xxx.com

# 1) 一键启动后端（venv + pip install + uvicorn 后台；自带旧 PID 清理）
bash deploy/onepress-install.sh

# 2) 看实时日志
tail -f logs/uvicorn.log            # 后端访问 / 应用日志
tail -f logs/nohup.log              # 启动期 stdout/stderr

# 3) 手动停 / 重启
kill $(cat logs/uvicorn.pid) 2>/dev/null ; rm -f logs/uvicorn.pid
bash deploy/onepress-install.sh     # 重启（脚本会 kill 旧的）

# 4) 探活
curl -s http://127.0.0.1:8000/health | python3 -m json.tool

# 5) 重新进入安装向导（重装）
cp -a .env ".env.bak.$(date +%s)"   # 先备份配置
rm -f .installed                    # 删除安装标记
# 然后浏览器打开 /install

# 6) 前端构建（需要 Node.js 18+，宝塔软件商店搜「Node 版本管理器」）
cd frontend
npm install
npm run build
cd ..
# 构建完刷新域名 / 即可看到 SPA 首页，不需要重启后端
