## 一、系统能做什么（1 分钟快速了解）

这是一套 **数字货币（币安 / OKX）+ AI 新闻情绪 + 策略打分引擎 + 回测 + 风控 + 财务报表** 一体化的策略交易系统，界面 14 个：

| 菜单 | 能做什么 | 谁能看 |
|---|---|---|
| 数据大屏 Dashboard | 今日盈亏 / 策略收益 / 持仓分布 / 账户余额 / AI 情绪总览 | 所有登录用户 |
| 交易所子账号 | 绑定币安 / OKX 主/子账号，连通性测试，同步余额/持仓/行情，取消所有挂单 | 所有登录用户（数据按**创建人**隔离）|
| 策略管理 | 选模板 / 建策略 / 打分 / 启停 / 一键跑实盘 / 看最新分数 | 所有登录用户 |
| 交易订单 | 手动下单 / 取消订单 / 查看订单历史 / 统计概览 | 所有登录用户（数据按**交易所账号**隔离）|
| 当前持仓 | 实时仓位 / PnL / 一键平仓 | 所有登录用户（数据按**交易所账号**隔离）|
| 新闻情绪 | 爬取 CoinDesk + 宏观新闻，AI 逐篇打分「看涨 / 看跌 / 中性」 | 所有登录用户 |
| AI 实时分析 | 输入交易对 + 时间窗口 + 提示词，AI 给方向 / 建议仓位 / 风险等级 | 所有登录用户 |
| 历史回测 | 选交易对 / 时间 / 起始资金 / 策略模板，跑历史数据，生成指标 + 净值曲线 | 所有登录用户 |
| 风控中心 | 单笔最大开仓 / 日最大亏损 / 单币最大仓位 / 暂停交易开关 | 所有登录用户（配置按创建人隔离，管理员可做全局）|
| 财务报表 | 日 / 月 / 年 PnL，总入金 / 出金，夏普、最大回撤、年化等 | 所有登录用户 |
| 用户管理 🔒 | 增删改查子账号，分配角色（admin / editor / 普通用户），重置密码 | **仅管理员** |
| 系统设置 | 会话时长、登录 IP 白名单、最大失败次数、审计日志开关、AI 模型 API 配置 | 所有登录用户（管理员能写全局）|
| 个人中心 | 修改昵称 / 头像 / 密码 / 查看自己的登录审计日志 | 所有登录用户 |

> 角色说明（seed_data.py 约定）：
> - `role=1` = 超级管理员（admin）：能看用户管理、写全局系统设置、查看全系统审计
> - `role=2` = 运营 / 编辑（editor）：能改策略 / 能手动下单 / 不能改用户和全局设置
> - `role=3` = 普通用户（user）：看自己绑定的交易所账号、看自己的策略、看自己的报表

## 二、管理员首次上线 · 6 步（必须按顺序做完，第一次约 10 分钟）

### Step 1 · 登录 + 改密码（必做，防止默认密码泄露）
1. 浏览器打开 `http://你的域名/` → 跳 `/login`
2. 输入你在 **`/install` 向导里填的管理员账号密码**（不是默认的 admin/Admin@2024，除非你向导里故意填回默认）
3. 登录成功 → 右上角头像 → **个人中心** → **修改密码** → 填旧密码 + 新密码（≥8 位、字母+数字）→ 保存
4. 右上角头像 → **退出登录** → 用新密码再登录一次，确认没记混

> 🎯 密码安全建议：用 1Password / Bitwarden 等密码管理器生成随机 16 位，不要和邮箱、交易所 API 共用。

### Step 2 · 系统设置（左侧菜单「系统设置」，建议一次配好）
点左侧菜单 **⚙️ 系统设置**，你会看到 6 项：

| 项 | 建议值 | 作用 |
|---|---|---|
| 站点标题 | 你的品牌名，比如「阿尔法量化工坊」| 前端登录页 + 侧边栏都会显示 |
| 时区 | `Asia/Shanghai`（国内）/ `UTC`（境外服务器）| 订单 / 报表 / 回测时间轴正确 |
| 允许登录 IP 白名单 | **如果你只用自己家/办公室 IP，就把这几个 IP 写上去，每行一个** ⭐⭐⭐⭐⭐ | 防止别人撞库后从陌生 IP 登录；写错会把自己锁出去（这时删 `.env` 里的 `AUTH_IP_WHITELIST=` 行并重启后端即可解锁）|
| 会话有效时长（分钟）| 默认 1440 = 24 小时；想安全就改成 480；想省事就 10080（7 天）| JWT token 过期时间 |
| 开启审计日志 | 勾上 ✅ | 管理员能在用户管理页看「谁什么时候干了什么」，强烈建议开 |
| 登录失败锁定次数 | 默认 5 次（超过锁定 30 分钟）| 防爆破 |

点「保存」→ 再去右上角头像退出重新登录一次 → 验证会话是否按预期。

### Step 3 · 配置 AI 模型（要 AI 新闻 / AI 实时分析才做，纯策略 + 手动交易可以跳过）
在系统设置页下方「AI 模型配置」区：
- 模型提供商：目前支持火山方舟（豆包/ML 平台）、阿里云百炼、OpenAI（兼容 API）三选一（下拉）
- Base URL：例如 `https://ark.cn-beijing.volces.com/api/v3` / `https://dashscope.aliyuncs.com/compatible-mode/v1` / `https://api.openai.com/v1`
- API Key：你的 Key（注意权限最小化，只给 chat:write 就行）
- 模型 ID：`doubao-seed-1.6-251015` / `qwen-max` / `gpt-4o-mini` 等
- 新闻分析开关：✅ 勾上 → 新闻页的每篇文章会自动跑 AI 打分
- （可选）代理池：如果服务器在国内要连 OpenAI，就在这里填 HTTP 代理，比如 `http://user:pass@1.2.3.4:7890`

点「保存」后，去左侧菜单 📰 **新闻情绪** → 随便点一篇 → 看右侧 AI 情绪卡片是否出结果，没有就去 `logs/uvicorn.log` 看报错。

### Step 4 · 绑定第一个交易所子账号（最核心的一步）
左侧菜单 💰 **交易所子账号** → 右上角「**＋ 新建账号**」：
1. 交易所：选 **币安（推荐先接测试网）** 或 OKX
2. 账号名：随便，如「币安-实盘-USDT本位」「币安-测试网-玩一玩」
3. API Key / Secret：
   - **强烈建议先接测试网**：币安测试网申请地址（百度一下 Binance Testnet），拿到测试网 API
   - 测试网：把下方「✅ 这是测试网」勾上
   - 权限：**只勾【读 + 下单】**，**千万不要勾提币权限** ❗（系统根本用不到提币，勾了就是增加被盗风险）
4. Passphrase（仅 OKX 需要）：OKX 创建 API 时自己设的那个短语
5. 代理（可选）：服务器在国内连不上币安就填 HTTP 代理，和上面 AI 代理格式一样
6. 起始资金：只是报表里展示用的基准，不会真的动交易所余额

保存 → 点账号列表里那一行的 **「🔌 连通性测试」**：
- ✅ 返回「成功 + 账户类型」 → OK，继续
- ❌ 返回 401「Invalid API key」 → 检查是不是填错了测试网/主网切换；是不是权限没选 Trading；是不是 IP 白名单没加服务器出口 IP（币安有这要求，很常见）
- ❌ 返回 -1021 Timestamp 5s 外 → 宝塔服务器时间不准，宝塔面板 → 计划任务 → 加一条「同步时间」每小时一次即可（或 `ntpdate ntp.aliyun.com`）

然后点 **「📥 同步余额」「📥 同步持仓」** 两次，看数据能拉到，就说明子账号 OK 了。

### Step 5 · 创建第一个策略 + 跑起来
左侧菜单 📊 **策略管理** → 右上角「**＋ 新建策略**」：
1. **从默认模板选一个**（推荐第一次就选「经典网格 + 趋势过滤」或「AI 情绪打分 + 均线金叉」，最简单不容易错）
2. 基本信息：
   - 策略名：随便，如「BTC-网格实盘-v1」
   - 绑定交易所账号：选刚才 Step 4 里那个测试网子账号 ⚠️ 第一次强烈建议选测试网
   - 交易对：`BTCUSDT`（模板通用，好验证）
   - 时间周期：15m（15 分钟 K 线，新手别改 1m，信号太密容易被手续费打死）
3. 参数：先用模板默认值，**一个字都别改**（等你跑出一轮结果再调）
4. 风控：先用默认值（最大开仓 0.05 BTC / 日最大亏损 2% / 单笔最大亏损 1%，对测试网很稳）

保存 → 回到策略列表 → 点行右侧 **「▶️ 启动」**：
- 绿色「运行中」+ 心跳显示最新 K 线时间 + 分数 = OK
- 想停就点「⏸ 暂停」，暂停后再点 ▶️ 会续上，不会丢状态
- 点「📈 最新分数」可以看这个策略在这个交易对的 24h / 7d 打分趋势

### Step 6 · 验收一轮闭环（看 Dashboard 有数据）
等 15~60 分钟（15m 周期就是每 15 分钟一根 K 线）：
- 去 📊 **数据大屏**：看「今日 PnL / 策略收益 / 持仓分布 / 余额」都不是空的
- 去 📝 **交易订单**：看有没有策略自动挂的单（测试网的话可以手动下一笔小的验证）
- 去 📍 **当前持仓**：看有仓位、PnL 实时动
- 去 📰 **新闻情绪**：点一下「📥 爬取最新」看有新闻进来 + AI 打过分
- 去 🧪 **历史回测**：跑一个 BTCUSDT 最近 30 天，看有没有净值曲线和指标（夏普、最大回撤、胜率）

6 个菜单都不是空的，就代表「管理员首次上线」完成 ✅。

## 三、交易员日常 · 10 分钟上手（普通用户 / editor 看完这章就够了）

### 3.1 每日打开 3 个页面
- 📊 **数据大屏**：5 秒扫一眼整体收益、今天的 AI 情绪、有没有红色预警
- 📍 **当前持仓**：看浮盈亏、有没有超过单笔风控阈值、要不要手动止盈止损
- ⚠️ **风控中心**：今天有没有触发暂停开关，有没有挂单异常

### 3.2 下一笔手动单（比如 AI 喊你加个仓）
1. 点 📝 **交易订单** → 右上角「手动下单」
2. 选交易所账号 → 交易对 → 方向（多/空）→ 市价 / 限价 → 数量 / 杠杆（合约才要）
3. 确认 → 点提交
4. 列表里立刻能看到 OrderStatus；不想要了点「取消」

### 3.3 想加仓 / 平仓
去 📍 **当前持仓** → 行右侧：
- 「💵 加仓」：按比例加
- 「🚪 一键平仓」：市价全部平掉（注意滑点，大仓位拆单更好）
- 「📝 设置止盈止损」：触发价 + 数量，策略引擎会自动扫

### 3.4 让 AI 分析一次（比如看 BTC 接下来 4 小时）
左侧菜单 🧠 **AI 实时分析** → 填：
- 绑定账号：Step 4 的那个
- 交易对：BTCUSDT
- 窗口：最近 200 根 K 线（或 4 小时）
- 问题：「请判断接下来 4 小时方向，建议仓位是多少，风控阈值给 3 个」
点「▶️ 分析」→ 30s 内会出：方向（多/空/中性）、建议仓位、风险等级、3 条风控建议。

### 3.5 想做历史回测（验证一个策略模板到底赚不赚）
点 🧪 **历史回测** → 右上角「＋ 新建回测」：
1. 选策略模板（要和 Step 5 实盘那个模板保持一致，参数也尽量对齐）
2. 交易对：BTCUSDT / ETHUSDT
3. 起止时间：最近 3 个月 ~ 1 年（越长越靠谱，别回测一周就下结论）
4. 起始资金：10000 USDT，滑点 0.1%，手续费 Maker 0.02% Taker 0.04%（币安现货大致水平）
点「▶️ 跑回测」→ 列表里会从 Running → Done → Done 点进去看指标：
- 累计收益率 / 年化 / 夏普 / 最大回撤 / 胜率 / 盈亏比
- 净值曲线图 / 每日 PnL 图 / 最大回撤区域图

> 💡 回测只能当参考。实盘加了滑点、冲击成本、交易所延迟、AI 新闻事件跳空，一般是回测收益打 6~7 折，**不要看到回测年化 100% 就激动，用测试网先实盘跑 2 周**。

## 四、管理员高级玩法 · 用户、审计、风控、报表

### 4.1 给同事开账号（🔒 管理员专属）
点 👥 **用户管理** → 右上角「＋ 新建用户」：
- 用户名 / 昵称 / 邮箱
- 角色：一般给 **普通用户（role=3）**；给运营同事给 editor（role=2）；新 admin 要非常谨慎（role=1 能看/改所有用户、所有 API Key）
- 临时密码：生成随机 16 位，让他第一次登录后立刻改（系统会强制改可自己加逻辑）

点创建 → 把用户名 + 临时密码发给同事，让他按上面 3.1 先登录改密码。

### 4.2 看审计日志（🔒 管理员专属）
用户管理页上方「审计日志」Tab：看「谁，什么时候，做了什么动作，IP 是多少，成功/失败」。配合 系统设置里的 **登录 IP 白名单** + **失败锁定**，基本能锁死 99% 的账号被盗攻击面。

### 4.3 全局风控开关（管理员在 风控中心 右上角「全局」Tab）
- **全局暂停所有策略**：勾选后，所有策略引擎只接收数据不下单（发生异常 / 交易所维护 / 团队开会时紧急停）
- **全局禁止手动下单**：防止交易员上头
- **单币最大仓位 / 单账号最大净敞口**：比如 BTC 最多不超过账号净值 50%
- 强平阈值：当账号净值跌破 XX% 时，自动取消所有挂单 + 平掉所有仓位（防止穿仓）

### 4.4 财务报表怎么导出
点 📄 **财务报表** → 选日期范围（日 / 月 / 年）→ 点「导出 Excel」/「导出 PDF」。审计、报税、给股东看都靠这一页。

## 五、运维日常 · 命令 / 日志 / 重启 / 升级

### 5.1 后端重启（宝塔部署）
```bash
cd /www/wwwroot/trade.xxx.com
# 稳一点：直接再跑一遍 onepress-install.sh（它会自动杀旧进程 + 启新的）
bash deploy/onepress-install.sh

# 或者手动 kill 再启
kill $(cat logs/uvicorn.pid) 2>/dev/null; rm -f logs/uvicorn.pid
nohup ./.venv/bin/python -m uvicorn main:app --host 127.0.0.1 --port 8000 --workers 4 >> logs/nohup.log 2>&1 &
echo $! > logs/uvicorn.pid
```

### 5.2 Celery 定时任务（要跑新闻定时爬 + 日报推送才需要）
```bash
cd /www/wwwroot/trade.xxx.com
# Worker（AI 新闻分析、日报生成、风控扫描）
nohup ./.venv/bin/python -m celery -A backend.core.celery_app:celery_app worker -l info --concurrency=4 >> logs/celery_worker.log 2>&1 &
# Beat（定时调度，比如每 15 分钟爬新闻 + 打分）
nohup ./.venv/bin/python -m celery -A backend.core.celery_app:celery_app beat -l info >> logs/celery_beat.log 2>&1 &
```

### 5.3 看日志 Top 5
```bash
cd /www/wwwroot/trade.xxx.com
tail -f logs/uvicorn.log          # 所有 HTTP 请求 / Python 报错
tail -f logs/nohup.log            # uvicorn 启动期 stdout/stderr
tail -f logs/celery_worker.log    # AI 新闻 / 日报是否按时生成
tail -f logs/celery_beat.log      # 定时任务有没有正常 tick
tail -f logs/strategy_engine.log  # 策略引擎心跳 / 下单 / 分数变化
```

### 5.4 升级（以后系统更新）
1. 备份！备份！备份！
   ```bash
   cp -a .env ".env.bak.$(date +%s)"
   mysqldump -uUSER -pPASS DBNAME > "db_$(date +%F).sql"   # 用 MySQL 才做
   cp -a trading_system.db "db_$(date +%F).db"              # 用 SQLite 就复制这个文件
   ```
2. 上传新 zip → 解压覆盖（不要删 `logs/`、`.env`、`.installed`、数据库文件！）
3. 升级脚本：`bash deploy/upgrade.sh`（自动 pip install 新依赖 + alembic 迁移 DB）
4. 重启后端：`bash deploy/onepress-install.sh`
5. 验收：`curl http://127.0.0.1:8000/health` → `installed:true`

### 5.5 探活 3 条（负载均衡 / 监控加这三条）
```
GET /health                                          → 200 + installed=true
GET /docs                                            → 200 Swagger UI
POST /api/v1/auth/login  (body: username+password)   → 200 + access_token
```

## 六、FAQ · 最常见 10 个问题 Top 10

### Q1 登录后立刻被踢回登录页 / 401
- 浏览器 DevTools → Application → LocalStorage → 看 `token` 是不是空？空就是后端返回 `access_token` 时写失败了（最常见是 `.env` 里 `APP_SECRET_KEY` 为空或者前后端域名对不上）
- 或者点 `/install` 向导里的 Step 3 时改了 `APP_SECRET_KEY`，但没重新登录（新密钥会让所有旧 token 失效）→ 重登一次就行
- 或者会话有效时长设置成了 0 分钟（系统设置里改回默认 1440）

### Q2 策略点「启动」后一直是「等待启动」/ Running 后很快变 Stopped
- 看 `logs/strategy_engine.log` + `logs/uvicorn.log`
- 80% 是：绑定的交易所账号连通性测试没过（IP 白名单 / 测试网 vs 主网 / 权限）→ 先回 Step 4 把连通性测试改成绿色再启动
- 15% 是：参数写错了（比如网格数量填 1 或 10000，超出上下限）→ 改成模板默认值再启
- 5% 是：数据库满了 / SQLite 只读 / 没磁盘空间了 → `df -h` 看磁盘

### Q3 新闻页全是「AI 分析失败」
- `tail -f logs/uvicorn.log | grep -i ai` 看报错
- 一般是：系统设置里的 AI 模型 API Key 错了 / 模型 ID 不对 / Base URL 少写 `/v1` / 国内服务器没走代理连 OpenAI
- 更隐蔽的：账号没额度（火山方舟 / 百炼要先买资源包或开通后付费）

### Q4 回测点运行永远 Running
- `tail -f logs/celery_worker.log`：看任务进没进 worker 队列，没有就是没开 Celery Worker / Worker 连不上 Redis
- 没装 Redis：第一次推荐干脆关掉 Celery 依赖，回测走同步线程也行（把 `USE_REDIS_BROKER=` 设空就能同步跑）

### Q5 手动下单返回 400 NoMarket / -4001 订单量太小
- 币安最小下单额大概 5~10 USDT，ETHUSDT 数量不要低于 0.002（举例，以交易所实际为准）
- 先到交易所子账号页点「同步余额」看余额够不够；下单前自己用计算器算一下 数量 × 市价 = USDT 总额 > 最小下单额

### Q6 登录不上管理员账号（密码忘 / 多次锁定）
- 最简单：重装向导（9.1 重装法）→ 重设
- 不想动数据：用 SQLite / MySQL 工具改 `users.password_hash`，生成一个新的 bcrypt hash（Python 一行：`from passlib.hash import bcrypt; print(bcrypt.hash('你的新密码'))` 写到 DB 里）
- 被 IP 白名单 / 失败次数锁了：
  - IP 白名单锁：编辑 `.env` 注释掉 `AUTH_IP_WHITELIST=` 行 + 重启后端，登进去再改对
  - 失败次数锁：等 30 分钟自动解锁；或直接 DB 里 `users` 表把 `locked_until` 设为 NULL

### Q7 所有 API 返回 500 / DB is locked（SQLite 模式最常见）
- SQLite 不适合并发大（5+ 策略 + 实盘下单建议切 MySQL）
- 临时解决：重启后端（`bash deploy/onepress-install.sh`）
- 长期：按部署教程 9.2 切 MySQL，5 分钟

### Q8 币安下单 -1022 Invalid signature
- API Secret 复制时多了空格（最常见 70% 案例）→ 重新复制粘贴，检查首尾没空格
- 服务器时间不准（Timestamp 差 5 秒以上）：宝塔 → 计划任务 → 加 NTP 同步
- 测试网/主网勾错了：实盘 Key 勾了测试网或者反过来

### Q9 前端页面白屏 / 资源 404
- 没 build 前端？→ `cd frontend && npm install && npm run build`，或者在宝塔里重新 npm run build 一次
- build 了但 /assets/xxx.js 404 → Nginx 片段里的 `alias` 路径写错了（对照部署教程 7.3 复制的片段，用真实站点根替换占位路径）
- 浏览器控制台报 CORS：后端 `.env` 里的 `CORS_ORIGINS=` 要加上 `http://你的域名,https://你的域名`，不要只加 `127.0.0.1`

### Q10 想关闭注册（或者开通注册）
- 现在默认没 `/auth/register` 接口，只有管理员在「用户管理」里加子账号 → **对 99% 团队就是对的**，不用额外关
- 要开放普通用户自注册：需要我帮你补 `/auth/register` 接口 + 邮箱验证码 + 图形验证码（可以加开关让管理员在系统设置里启用/关闭），回我一句「加用户自注册」我就帮你补上。
